- [ ] Recordings are saved in private application storage.

# 30. FINAL RELEASE DECISION RULES

Use the following release statuses.

## READY FOR SUBMISSION

All mandatory acceptance criteria pass.

Required localised screenshots, metadata, privacy documentation, billing verification, and device compatibility checks are complete.

No unresolved critical defects remain.

## CONDITIONALLY READY

Core functionality passes, but clearly identified non-critical work remains.

Do not describe this state as fully production-ready.

## BLOCKED

One or more critical requirements are failed, incomplete, or unverified.

Examples:

- Android build fails.
- Audio recording loses data.
- Required translations are incomplete.
- Localised screenshots are missing.
- Amazon billing is unverified.
- Backup restoration loses content.
- Critical security issues remain.
- Required Fire tablet testing has not been completed.

Do not mark a BLOCKED application ready for submission.
