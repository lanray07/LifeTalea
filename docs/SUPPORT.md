# LifeTalea support

Publisher: O.Bankole. Email: banksmi@mail.com. Source and issue tracking: https://github.com/lanray07/LifeTalea.

LifeTalea is a development preview. Keep a local backup before uninstalling or replacing a build. The debug and production packages have separate storage.

To record, save a memory first, check microphone permission and free storage, then choose Record a story. Leaving the app stops and saves the recording. Touch and text alternatives work independently of a speech-recognition engine. Automatic recorded-file transcription is not configured.

For backup, choose whether to include photos and audio, create the archive through Settings, and save it somewhere safe. Keep its passphrase separately. Restore shows a preview and keeps existing records on conflicts. The current archive implementation is limited to 32 MiB overall and 16 MiB per attachment and can need substantial working memory. Larger or long-recording libraries need a future streaming implementation.

When reporting a problem, include the app version, device model, OS version and repeatable steps. Do not include private recordings, photographs, memory archives, API credentials or passphrases in public GitHub issues. Purchases are unavailable until the correct Amazon integration and test configuration are complete.
