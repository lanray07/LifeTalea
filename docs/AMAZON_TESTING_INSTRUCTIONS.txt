No LifeTalea login is required. Use fictional demonstration content on a dedicated Fire tablet. Microphone permission is requested only after choosing to record. The application has touch and text alternatives to installed speech services.

Core walkthrough:
1. Open LifeTalea. Complete or skip onboarding. Add a memory with a title and written story; optionally enter tags, location and a year/month/day/unknown date. Save, reopen and edit it.
2. Import a photograph with the system file picker. Create an album and add the memory. Search its story/tags/manual transcript, mark it as a favourite and find it in the timeline.
3. Open the memory and choose Record. Review the microphone notice, grant permission, record a short fictional story, pause/resume and stop. Play it and use the seek control. Free recordings are limited to three minutes. Do not record private conversations for testing.
4. Edit the transcript manually. Automatic recorded-file transcription is NOT configured. Installed speech recognition and spoken playback vary by device; command phrases currently support English only.
5. Duplicate the memory. The copy should have independent photograph/audio files and the same album membership. Deleting the original must leave the copy playable/readable.
6. Create a keepsake draft, add a memory, reorder pages and edit a caption. Premium PDF export is not available to production users in this candidate.
7. In Settings, create an unencrypted backup to a location you control, explicitly selecting whether to include photos/audio. Preview and restore it. Existing memories/books are retained. The importer is bounded to 32 MiB total, 16 MiB per attachment and 8 MiB manifest; exports can fail above those limits. This is not a streaming large-library implementation.
8. Close and reopen the app and confirm saved content. Delete test records through the app and delete any exported copies separately.
