LifeTalea 0.1.0 / version code 1 — development review and billing test notes
Publisher: O.Bankole | Support: banksmi@mail.com | Package: com.lifetalea.app

The standard unsigned release candidate is purchases-disabled. A separate unsigned amazonTest candidate connects to the deployed Supabase production verifier and is intended only for Amazon Live App Testing. Do not publish a QA/debug APK. The LAT upload SHA and Amazon test status are recorded in amazon-lat-apk-inspection.json and amazon-console-review.json.

No LifeTalea login is required. Use fictional content on a dedicated Fire tablet. Microphone permission is requested only when recording is chosen. Touch and text alternatives are available.

Core walkthrough:
1. Complete or skip onboarding. Add a memory with a title/story, tags, location and approximate or exact date. Save, reopen and edit.
2. Import a photograph with the system picker. Create an album, add the memory, search story/tags/manual transcript, favourite it and inspect the timeline.
3. Record a short fictional voice story. Pause/resume/stop, play it and seek. Free recordings are limited to three minutes. Avoid private recordings.
4. Edit the transcript manually. Automatic recorded-file transcription is not configured. Installed speech/TTS services vary by device; command phrases currently support English only.
5. Duplicate a memory. Delete the original and verify the duplicate retains independent photo/audio and album membership.
6. Create a keepsake draft, add/reorder memories and edit a caption.
7. Export a basic backup with explicitly selected media. Preview and restore it. Existing content is retained. Current importer limits: 32 MiB total, 16 MiB per attachment, 8 MiB manifest. Large-library streaming is incomplete.
8. Reopen offline and check saved content. Delete test records and exported copies separately.

LAT billing checklist (only after Amazon publishes this test):
- Use the assigned Amazon tester account and the Amazon-processed LAT install. Check the device shows a test transaction before proceeding; do not make a real-money purchase.
- Purchase com.lifetalea.premium. A successful SDK callback alone must not grant access: the app must receive a valid signed active receipt result from the deployed verifier before fulfillment.
- Verify Premium album/long-recording/PDF/encrypted-backup benefits, restore, canceled-dialog behavior, failure/retry, account changes, cancellation/refund and offline/reboot recovery.
- Record exact processed APK hash, device/OS, result and redacted evidence. Never publish user IDs, receipts or secrets.

Executed evidence: real App Tester sandbox purchase/restore/cancellation passed after fixing SDK-canceled receipt precedence; five fixed-build cases are retained. The deployed production service passed HTTPS health and signed rejection of synthetic invalid identifiers. No LAT purchase result is claimed yet.

Languages: the standard release and LAT candidate are English. The separate debug package has 22 draft locales and 176 current-APK screenshot compositions, with zero native release approvals.
