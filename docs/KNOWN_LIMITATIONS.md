# Known limitations and remaining engineering

This is a development build. Release readiness is BLOCKED independently of whether a source component compiles.

Latest evidence: `AMAZON_TRANSCRIPTION_RELEASE_REVIEW_2026-11-07.md` and `deliverables/reports/transcription-2026-11-07/`. Version 4 is a local candidate, separate from Amazon version 3; it is not yet an Amazon-distributed build.

- Recorded-file transcription now uses a bundled Whisper model with editable review and append. Short English AAC, cancellation/retry, source preservation on failure and an actual process restart passed on Fire. Other-language accuracy, long-running/low-memory/background behavior and broader device coverage remain unverified. The ten-minute guard is an implementation limit.
- App, website and store drafts cover 22 locales. All 199 app keys pass structural validation. An authored editorial pass corrected app wording, rewrote the complete non-English article set and aligned store copy; native approval remains absent. Draft app resources are debug-only. Landscape tablet screenshots exist; other device sizes, native review and full visual/accessibility checks remain incomplete. See TRANSLATION_POLISH.md for current checks.
- English voice commands accept an album name or a year and clear unrelated filters when opening that view. Other command dictionaries are pending. Recognition and spoken playback depend on installed services and require locale-specific tests. Audio seek, focus interruptions, permission denial and long recordings need broader tests.
- Amazon’s matching public authentication key is bundled. Premium is Approved for TEST at the approved GBP4.99 UK price and calculated marketplace prices. The isolated Supabase verifier is deployed and signed production invalid-receipt smoke passed. Real App Tester sandbox purchase/restore/cancellation passed after fixing canceled-receipt precedence. One version 1 LAT purchase activated Premium through signed verification. Version 2 passed update continuity, fresh-tablet restore and a post-reset cold-launch prompt and cancellation check. Public submission remains blocked. See AMAZON_LAT_STATUS.md. Standard release purchases stay off. In-app hosted-verifier disclosures and the final store privacy questionnaire still require review. See AMAZON_SUPABASE_DEPLOYMENT.md and AMAZON_RVS_IMPLEMENTATION.md.
- Current backup uses bounded in-memory archives: 32 MiB total, 16 MiB per item, with conservative creation reserve. Large photos or long recordings may exceed the cap. Streaming export/restore, crash journalling and fuzz/low-memory tests remain necessary.
- Scrapbooks use simple story/photo page arrangements and one editable caption per page. There is no freeform drag canvas. PDF exports use the first photograph per selected memory; multi-photo printable layouts, contents pages and richer cover typography remain enhancements. PDF preview uses scrapbook preview rather than an embedded PDF viewer.
- Onboarding saves the selected purpose and uses it to choose an existing localized story prompt. Album and first-memory creation are available after onboarding. Reminders, optional app lock, advanced search controls, premium theme differentiation and a larger prompt catalogue are incomplete. Current search includes title/story/tags/transcript/location/date and an album filter.
- There is one Gradle application with package boundaries, not a full independent-module Clean Architecture graph. No previous database release exists, so future migrations still require new test fixtures and explicit migration code.
- Two Fire HD 10 tablets have been tested. Other Fire sizes, portrait, accessibility services, large font settings, performance budgets and prolonged offline use need a complete device matrix. No Fire TV UI exists.
- The marketing site is a local static preview. GitHub source/policy/support URLs are provided; no production website or store listing is published. Final locale availability, country selection, signing/update identity, native-language review, privacy/legal review, asset polish and name clearance remain required.

These limitations are included to keep source delivery, implemented behaviour and release approval distinct. They must not be omitted from a public launch decision.
