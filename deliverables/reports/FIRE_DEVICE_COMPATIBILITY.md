# Fire device compatibility

Available physical device: KFTRWI, Fire OS 7.0, Android API 28, 1200×1920 physical panel (landscape application captures). Final instrumentation suite: PASS. Diagnostic details are in voice-device.json when retained.

A single device does not certify all Fire tablets. Other sizes/OS versions, portrait coverage, font scaling, physical denial/interruption cases, recognition/TTS language quality and Amazon purchasing need explicit tests. The tested device reports no speech-recognition service; IVONA and Pico TTS services are installed but language quality is unverified. No Fire TV support is claimed.
