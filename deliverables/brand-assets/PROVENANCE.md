# Asset provenance

Book/waveform logo, adaptive icon, monochrome and editable cover/background templates: original project vector geometry, generated by scripts/create_assets.py. Master raster is a deterministic rendering of this identity.

hero-book.png and design-concept.png: generated with the built-in OpenAI image tool for this project on 2026-11-02; no reference photographs or competitor artwork supplied. Production illustration is hero-book.png; design-concept.png is a design reference, never an application screenshot.

Editable splash, onboarding, empty-state, upgrade, timeline, voice-waveform, keepsake-cover, promotional, social and wordmark variants are generated by scripts/asset_package.py. These intentionally reuse the original book identity/illustration and original vector geometry. They are brand source artworks, not app screenshots, and require final visual/export review. The app currently uses the shared original book illustration and Material icons. Dependency icons retain their upstream Apache licence.
